# Tallers de React

Material per aprendre React pas a pas. Les fitxes proposen teoria i activitats
progressives que construeixen un mateix projecte. Recomanem fer-les en ordre i
provar el codi a mesura que avances.

## Requisits

- **Node.js 22.22.2 o superior** i npm, inclòs amb Node.js. Les fitxes més
  avançades necessiten aquesta versió.
- Un navegador actual.
- Un editor de codi. Git és recomanable per descarregar el repositori i desar
  els canvis.

Descarrega Node.js: [nodejs.org](https://nodejs.org/en/download/). Si encara no
fas servir Git: [git-scm.com](https://git-scm.com/downloads).
